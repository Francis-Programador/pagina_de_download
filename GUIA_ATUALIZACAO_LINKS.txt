================================================================================
OPÇÕES DE ARMAZENAMENTO DE ARQUIVOS E IMAGENS
================================================================================

GOOGLE DRIVE (Recomendado - Gratuito)
──────────────────────────────────────
1. Acesse: https://drive.google.com
2. Envie o arquivo (planilha, script, PDF, etc)
3. Clique com botão direito > Compartilhar
4. Configure para "Qualquer pessoa com o link pode visualizar"
5. Copie o ID da URL (entre /d/ e /view)

Exemplo de ID: 1ABC123DEF456GHI789JKL

Use assim:
Para DOWNLOAD:
  https://drive.google.com/uc?export=download&id=SEU_ID_AQUI

Para VISUALIZAR/IMAGEM:
  https://drive.google.com/uc?export=view&id=SEU_ID_AQUI

YOUTUBE (Para vídeos - Gratuito)
─────────────────────────────────
1. Acesse: https://youtube.com
2. Envie seu vídeo (Público ou Não listado)
3. Copie o ID do vídeo (após watch?v=)

Exemplo: https://www.youtube.com/watch?v=dQw4w9WgXcQ
ID: dQw4w9WgXcQ

Use assim em links diretos:
  https://www.youtube.com/watch?v=dQw4w9WgXcQ

Use assim em iframes (embeds):
  <iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ"

ARMAZENAMENTO LOCAL (Sem internet)
───────────────────────────────────
Coloque arquivos na pasta: assets/img/

Exemplo:
  assets/img/minha-imagem.jpg
  assets/img/print-planilha.png

Use assim:
  <img src="assets/img/minha-imagem.jpg" alt="Descrição">

Para downloads locais - coloque em uma pasta e use:
  <a href="assets/files/meu-arquivo.zip">Download</a>

OUTRO SERVIDOR / SITE PRÓPRIO
──────────────────────────────
Se você tem um servidor ou site:
  https://seusite.com/downloads/arquivo.zip
  https://seusite.com/images/imagem.jpg

PASSO A PASSO PARA ATUALIZAR (Método Simples)
================================================================================

1. Abra o arquivo HTML que quer editar (ex: planilhas.html)

2. Use Ctrl+H para LOCALIZAR E SUBSTITUIR

3. Na caixa "Localizar", digite:
   href="#"

4. Na caixa "Substituir por", coloque o seu novo link:
   href="https://seu-link-aqui.com"

5. Clique "Substituir" (cuidado para não substituir acidentalmente)

OU faça manualmente:
   - Procure por href="#"
   - Clique no local
   - Apague o #
   - Digite seu link
   - Salve (Ctrl+S)

3. COPIE todo o card (do <article até </article>)

DÚVIDAS EXTRAS
================================================================================

P: Vou bagunçar o site se copiar e colar?
R: NÃO! Desde que você copie a estrutura INTEIRA (do <article até </article>),
   será exatamente igual. Só mude o conteúdo.

P: Quantos cards posso adicionar?
R: Quantos quiser! O site se ajusta automaticamente.
   Em desktop: 3 colunas
   Em tablet: 2 colunas  
   Em celular: 1 coluna

P: Posso reordenar os cards?
R: Sim! Corte e cole em outra posição. O primeiro que aparecer no código
   aparecerá primeiro no site.

P: E se eu quiser remover um card?
R: Procure pelo card todo (<article class="card">...</article>) e DELETE.
   Cuidado para não deixar código quebrado.

P: Como testar antes de publicar?
R: 1. Salve o arquivo (Ctrl+S)
   2. No navegador, aperte F5 ou Ctrl+Shift+Delete
   3. Verifique se o novo card aparece
   4. Clique nos botões para testar links

P: Os links de iframes funcionam igual?
R: Sim! Use a mesma estrutura, só mude o ID:
   Antes: <iframe src="https://www.youtube.com/embed/VIDEO_ID_AQUI"
   Depois: <iframe src="https://www.youtube.com/embed/SEU_ID_NOVO"

P: Posso usar a mesma imagem em vários cards?
R: Sim! Use o mesmo caminho:
   <img src="assets/img/placeholder.svg">
   Todos usarão a mesma imagem.

P: E se eu quiser imagens diferentes?
R: Coloque as imagens na pasta assets/img/ e use:
   <img src="assets/img/sua-imagem.jpg">
